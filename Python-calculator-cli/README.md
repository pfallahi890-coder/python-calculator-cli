# Python Calculator (CLI)

A simple command-line calculator that performs addition, subtraction, 
multiplication, and division.

## How to run

It asks you to enter a number at first and choose the calculation you want to do . And simply you put numbers as much as you want . at the end , you type "exit" and get your result.


## What i learned 

- Using `while` loops and `break` to control program flow
- Conditional logic with `if` / `elif` / `else`
- Taking and validating user input
- Handling exceptions with `try` / `except`
- Handling edge cases like division by zero and invalid input
